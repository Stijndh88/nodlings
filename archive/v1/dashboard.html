The headline is skill: how much better the evolved Nodlings score on a fixed exam than Nodlings with random brains (higher is better). What do these numbers mean?

Nodling
One of the little creatures in the simulation. Each has a small evolving "brain"; nobody scripts what it does.
What is the loop?
An unattended routine that keeps the world running. Each "cycle" it simulates a long stretch of time, measures how the Nodlings are doing, tries one small change to the rules, tests it, and keeps or reverts it.
Cycle
One run of that routine. The cycle number counts up over time.
Day
In-world days since the world started (one day is 1,600 simulation ticks). It only measures how long the world has been running, not how well it is going.
Skill (the headline number)
An exam for the species. A sample of 40 living Nodlings is copied into fresh, identical test worlds and scored on how long each lives and how many offspring it has. There are three tasks: a normal world, a world with little food, and a world where thirst bites five times faster. The same exam is given to Nodlings with random brains. Skill is the evolved score minus the random score, averaged over the tasks. The exam never changes when the live world is made harder, so a rising line means the Nodlings really got better.
Learning gain
The exam score with learning switched on, minus the score of the same Nodlings with learning switched off. It answers "does learning during a lifetime actually help them?". Positive means it helps. At or below zero means the brains do not use learning yet, which is where the project started in November 2026.
Memory gain
The same idea for memory: the normal exam score minus the score when the memory senses (remembered food, water and shelter, plus the two memory cells) are blanked. A large positive number means the Nodlings rely on memory.
Brain size
Average number of connections in a living Nodling brain. Not a goal by itself, but a collapse suggests that thinking no longer pays.
Median fitness
The middle score of the Nodlings alive right now, where score = age in ticks + 250 per offspring. It swings as old Nodlings die, so read the trend, not one value.
Max generation
The longest family line alive: how many parent-to-child steps separate it from the first Nodlings.
Old benchmark gap
The headline until cycle 228. It let the test colony breed until it filled the map, so it mostly measured how fast a colony grows and it barely moved for a month. Replaced by Skill.
Population
How many Nodlings are alive right now. It is capped (currently 500), so it normally sits near the cap; a sudden drop would mean trouble.
Instant test
A quick check of a rule change: the same living Nodlings sit the exam under the old and the new rules, on several sets of test worlds. It shows the immediate effect of the change.
Evolution experiment
The real test of a change. Several copies of the world evolve for about 40 days with the change and several without it, on GitHub Actions. A change is kept only if the Nodlings that evolved with it score measurably higher on the exam. One run per side proves nothing: identical rules can differ by 5 to 55 percent between two runs.
INCIDENT
A guardrail tripped on a plain run, so the loop stopped changing things and left a note in the changelog for a human to look at.
STRUCTURAL
A changelog tag for a change that adds a new rule or reward, as opposed to just nudging an existing number.
